# SULPHUR — Architecture guide (for every contributor)

Roguelike narrativo top-down en los 9 círculos del Infierno. Three.js + Vite. **All art, sound and music are generated by code** — there are no asset files. Everything must belong to one coherent visual universe: dark, gothic, expressionist pixel art inspired by La Divina Comedia. No neon, no sci-fi, no cartoon, no generic fantasy.

Run: `npm run dev` → http://localhost:5173 . Dev URLs: `/?sandbox&c=2` (one combat room of circle index 2, endless waves), `/?run&c=3` (start a run at circle index 3), `/?hub`.

## Rendering model (read this before drawing anything)
- World units: 1 unit = 16 texels (`PPU`). Camera: fixed orthographic 3/4 view, pitch 50°. Floor cells are `1 x TZ` (TZ = 1.305) so floor texels map 1:1 to screen pixels.
- The scene renders into a low-res target (~270px tall) and is upscaled with nearest filtering → true pixel art. Lighting is quantized + Bayer-dithered (src/render/lighting.js).
- Characters/props are **upright billboard sprites** (`src/render/sprite.js` → `new Sprite(sheet, {anim, pivot, scale, unlit, minLight})`). Sprites are side-view, facing RIGHT; flipped for left.
- Sprite sheets are drawn procedurally: `new SpriteSheet({ w, h, emissive: true, anims: { name: { frames, fps, loop, draw(c, e, i, n) } } })` (src/art/sheet.js). `c` = color `PixelCanvas`, `e` = emissive `PixelCanvas` (pixels painted there glow and feed bloom). A 1px dark outline is added automatically (disable with `outline: false`). Leave ≥1px transparent margin inside each frame.
- `PixelCanvas` (src/art/pixel.js): `set(x,y,c)`, `rect`, `hline`, `vline`, `line`, `thickLine(x0,y0,x1,y1,r,c)`, `ellipse(cx,cy,rx,ry,c, shadeFn)`, `disc`, `ring`, `poly(pts, c, shadeFn(x,y))`, `stamp(rows,x,y,pal)`, `outline`, `selout`, `map`, `blit`, `erase`, `alpha(x,y)`. Shade with ramps + `bayer(x,y)` dithering — light comes from top-left. Use `getSheet(key, factory)` to cache.
- Palettes: `src/art/palette.js` — `R` (shared ramps: blood, ember, ice, gold, holy, crimson, shadow, bone, steel, poison, violet, wood, stone, bronze, teal, soul, skin, skinPale…) and `CIRCLE_PALETTES[circleId]`. Ramps go dark→light. Use them; don't invent off-palette colors.
- Reference implementations: `src/art/figure.js` (humanoids), `src/art/enemies/limbo.js` (enemies), `src/art/bosses/minos.js` (boss), `src/art/props.js` (props), `src/art/fx.js` (effects).
- Recommended enemy frame sizes: small 24–28px, medium 32–40px, large/minibosses 48–64px, bosses 72–110px. Anim names: `idle, move, windup, attack, hurt, death` (+ any extra like `roar`, `cast`, `charge`).

## Gameplay model
- `World` (src/game/world.js): `player`, `enemies`, `projectiles`, `pickups`, `interactables`, `hazards` (objects with `update(dt)`, `done`, optional `destroy()`/`disarm()`), `room` (grid, collision, `los`, `raycast`, `free`, `randomFloor`, `bounds`), `fx`, `lights`, `controller` (current game state: `spawnEnemy(id,x,z,opts)`).
- Coordinates: x right, z down-screen (toward camera). Angles are `atan2(dz, dx)`.
- Combat (src/game/combat.js): hits are data — `{ team:'enemy'|'player', shape:'circle'|'arc'|'line'|'ring', x,z, angle, radius, range, arc, length, width, damage, knockback, stagger, element:'physical'|'holy'|'fire'|'ice'|'corrupt'|'poison'|'wind'|'gold', status:{burn|poison|slow|freeze|stun|curse:{amount,dur}} }`. `resolveHit(world, hit)` applies it with full feedback (hitstop, flash, particles, numbers, shake). Elements drive the VFX colors.
- Enemies (src/game/enemy.js): `registerEnemy(def)` with
  `{ id, name, circle, hp, speed, radius, mass, mode:'walk'|'fly', blood:'blood'|'ichor'|'ecto'|'bile'|'gold'|'ember'|'ice'|'smoke', poise, armor, touch (contact dmg), sheet:(e)=>SpriteSheet, pivot, scale, aura (particle preset), light:{color,intensity,radius}, spawnRamp, deathPreset, deathEdge, init(e,o), think(e,dt), onHurt(e,hit,dmg), onDeath(e,hit), desc }`.
  Enemy toolkit: `e.chase(mul)`, `e.steer(angle,mul)`, `e.keepDistance(min,max)`, `e.moveToward(x,z)`, `e.stop()`, `e.faceTarget()`, `e.faceAngle(a)`, `e.distToTarget()`, `e.angleToTarget()`, `e.hasLos()`, `e.cd(name,secs)`/`e.ready(name)`, `e.after(secs,fn)`, `e.play(anim,{restart})`, `e.telegraph({shape:'circle'|'cone'|'rect'|'ring', radius, halfAngle, angle, length, width, duration, follow})`, `e.strike(hitData)`, `e.shoot(projOpts)`, `e.ring(n,opts)`, `e.spread(n,arc,opts)`, `e.ai` (free state bag), `e.elite`, `e.purified`, `e.dmgMul`, `e.teleMul` (multiply your windups by it), `e.speed`.
  Behaviour patterns `B.melee(e,dt,{range,arc,windup,damage,knockback,lunge,track,recover,cooldown,shape})`, `B.charge(e,dt,{windup,length,speed,damage,cooldown,minRange,maxRange})`, `B.volley(e,dt,{windup,shots,interval,range,cooldown,fire:(e,i)=>{}})`, `B.wander`, `B.explode(e,{radius,damage,ramp,key})`. Each returns true while busy — return from `think` when true.
- Projectiles (src/game/projectile.js) options: `{ x,z,y, angle, speed, damage, radius, life, kind:'orb'|'wisp'|'bolt'|'shard'|'coin'|'skull'|'arrow', ramp:[4-6 colors], size, pierce, homing, curve, accel, wobble, bounce, element, status, trail:'presetName', light:color, onExpire }`.
- Bosses (src/game/boss.js): `registerBoss({ ...enemyDef, boss:true | miniboss:true, title, phases:[0.6,0.3], patterns:{ 0:[{id, weight, cd, range:[min,max], cond(b), run(b,dt,S)=>'done'}], 1:[...], 2:[...] }, idle(b,dt), intro:[dialogue steps], outro, onPhase(b,phase), arena(world,b,controller), deathRamp, pillarRamp })`. `S` is a per-pattern state bag, `S.t` = time in pattern. See `src/game/bosses/minos.js`.
  Minibosses: same API with `miniboss: true, showBar: true`.
- FX (src/render/fx.js): `fx.emit(preset,x,y,z,count,{dir,spread,speed,radius,c0,c1,size})`, presets in src/render/particles.js (spark, fire, ember, holy, holyMote, corruption, corruptGlow, blood, bloodMist, ice, frost, wind, poison, bile, gold, ash, smoke, dust, soul, shadow, lightning, petal); `fx.ring`, `fx.line`, `fx.play(sheet,{x,y,z,angle,scale,onTop,additive,follow})` for one-shot sprite effects (explosionSheet, impactSheet, pillarSheet, spawnSheet, slashSheet, thrustSheet in src/art/fx.js), `fx.decal(name,x,z,size,{fade,alpha,color,unlit,glow})`, `fx.telegraph(...)`, `fx.lightFlash(x,z,color,intensity,radius,dur)`, `fx.shake(0..1)`, `fx.screenFlash(color,alpha,dur)`, `fx.aberration(a)`. `world.lights.add({x,y,z,color,intensity,radius,flicker,follow})`.
- Events bus (src/core/events.js) — every meaningful moment is an audio hook. Emitted names: `attack:light, attack:heavy, attack:charge, attack:charged, attack:special, attack:windup, hit, hit:heavy, dash, dodge:perfect, enemy:spawn, enemy:windup, enemy:attack, enemy:shoot, enemy:death, explosion, pickup, gold, essence, fragment, player:hurt, player:heal, player:lowhp, player:death, player:revive, moral:choice, moral:absolve, moral:condemn, moral:change, moral:tier, dante:transform, boss:intro, boss:appear, boss:phase, boss:pattern, boss:windup, boss:slam, boss:roar, boss:death, miniboss:appear, miniboss:death, victory, dialogue:open, dialogue:close, dialogue:line {speaker, voice, text}, dialogue:blip {speaker}, room:enter {node, circle}, room:clear, wave, door:open, door:enter, door:reveal, reward:appear, boon:gain, relic:gain, altar:virtue, altar:sin, shop:buy, rest, beatriz:appear, titlecard {circle}, circle:start {circle}, interlude:enter, hub:enter, title, run:start, run:end, ending {id}, trap:arm, trap:fire, wind:telegraph, step, ui:hover, ui:click, ui:deny, ui:open, ui:start, state {name}, settings`.

## Narrative model
- Dialogue scripts (src/game/dialogue.js): arrays of steps — `['speaker', 'text' | (ctx)=>text, {mood:'sad'|'angry'|'smile'|'shout', name}]`, `{choice:[{t, then:[steps], fx:{virtue,sin,doubt,flag,runFlag,gold,heal,essence,fragment}, tag:'doubt'|'virtue'|'sin', cond(ctx)}]}`, `{if:(ctx)=>bool, then:[...], else:[...]}`, `{fx}`, `{event:'name'}`, `{moral: soulId}`.
- `ctx`: `run, meta, moral, tier (-2..2), balance, circle, circleIndex, flag(k), runFlag(k), seen(id), soul(id) → {absolved, condemned, last}, decided(id), runs, deaths, victories, absolvedTotal, condemnedTotal`.
- Registry `src/data/dialogue/index.js` (ID prefixes documented there). Selection by prefix with `cond`, `once`, `priority`.
- Speakers + portrait parameters: `src/data/speakers.js` (portrait painter: src/art/portraits.js).
- Souls & dilemmas: `src/data/souls.js` (schema at the top of the file). Absolve → Virtue; Condemn → Sin + power.
- Moral system: `src/game/moral.js` (tiers −2 Caído … +2 Santo; GDD dynamic difficulty; resolveEnding).

## Language
All player-facing text is **Spanish**. Short quotes of Dante's original Italian (public domain) are welcome for flavor.
